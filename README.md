# 🚀 Minha Jornada Tech: Linux, Redes e Programação

Bem-vindo(a) ao meu portfólio de estudos práticos! Este espaço foi criado para documentar toda a minha evolução saindo do zero absoluto em tecnologia.

O meu objetivo final é construir um projeto completo que une essas três áreas: um **Analisador Automatizado de Redes**.

---

## 📚 Minhas Trilhas de Aprendizado:

### 💻 1. Lógica de Programação (Python)
- **O objetivo:** Criar um script (um robô) que testa se uma lista de sites da internet está funcionando ou fora do ar.
- **O que vou aprender:** Variáveis, condições (Se o site responde ou não) e repetições automáticas.

### 🌐 2. Redes de Computadores
- **O objetivo:** Mapear a rede da minha própria casa, entendendo como as informações viajam pelo Wi-Fi e roteador.
- **O que vou aprender:** O que é Endereço IP, como funciona o comando `ping` e caminhos de rede.

### 🐧 3. Sistema Operacional Linux (Ubuntu)
- **O objetivo:** Fazer o robô de Python rodar sozinho em segundo plano dentro do Linux de forma segura e agendada.
- **O que vou aprender:** Comandos de terminal, pastas do sistema e automação de tarefas.
