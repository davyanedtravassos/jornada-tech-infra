# 🌐 Trilha de Redes de Computadores

Nesta pasta, vou documentar meus aprendizados sobre como os computadores conversam entre si e como a informação viaja pela internet.

## 🎯 O que vou aprender:
* **Endereçamento IP:** Entender o que é o "CEP" ou o "endereço residencial" de cada dispositivo na rede.
* **Comando Ping:** Como enviar um sinal de "olá, você está vivo?" para um servidor e medir o tempo de resposta.
* **Protocolos de Comunicação:** Como as regras do mundo digital garantem que uma mensagem chegue inteira e sem erros ao destino.
